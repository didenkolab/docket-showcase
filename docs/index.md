# Harbor

The front page of this vault's knowledge base. Replace this with whatever a newcomer to
Harbor should read first.

The tree under `docs/` is free — put a page wherever it makes sense — but a page is not
shapeless. Every one carries `title`, `type` and `updated`, and `type` says what kind of document
it is: a decision, a design page, a spec, a sprint, or a page. [[documents]] is the whole of it,
and it is the file to read before writing a decision or a spec.

Connect pages with `[[wikilinks]]`, so the graph view and backlinks stay worth opening, and do
not write a page whose purpose is to list other pages.

Tasks link to pages and pages link back. That shared link layer is the whole of the integration
between the board and the knowledge base.
